# Crawled Data Directory

This directory contains all data crawled by the Selenium script.

## Files Generated

After running the crawler, you will find:

- `crawled_data.json` - Full JSON data with structure and metadata
- `crawled_data.xlsx` - Excel file with multiple sheets
- `crawled_data.csv` - CSV file with student data
- `page_loaded.png` - Screenshot of the loaded page
- `crawl_complete.png` - Screenshot after crawl completion

## Directory Structure

```
crawl_data/
├── crawled_data.json
├── crawled_data.xlsx
├── crawled_data.csv
├── page_loaded.png
└── crawl_complete.png
```

## Note

This directory is automatically created when you run the crawler script.
